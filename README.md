# Brian Maina Portfolio

A modern, interactive personal portfolio website built to showcase projects, skills, and blog posts. 

## Tech Stack & Features

This project utilizes a robust stack of modern web technologies:

* **Framework:** Next.js with React 19
* **Styling:** Tailwind CSS and Shadcn UI for beautiful, responsive design
* **Animations:** Framer Motion, React Scroll Parallax, and tsParticles for dynamic visual effects
* **Database & Storage:** MongoDB for data storage and Vercel KV for fast key-value operations
* **Rate Limiting:** Upstash Ratelimit to protect API endpoints
* **Email Handling:** Resend and React Email components for seamless communication
* **Document Preview:** Integrated PDF and PPTX preview capabilities
